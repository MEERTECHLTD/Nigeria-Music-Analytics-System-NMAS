# Pipeline Map — source to every displayed number

## Canonical source layer

Two origins, with defined precedence:

1. **Soundcharts API** — live and re-queryable. `backend/nmas/services/soundcharts.py`
   extracts to `backend/data/soundcharts/{shards,geo_full,full_entity}/`.
   Verified 2026-08-17: 25 of 25 randomly sampled delivered values re-queried
   against the live API matched exactly (`_audit/validation/live_requery.txt`).
2. **Chartmetric-era outputs** — `delivery/04_Datasets/*`. IMMUTABLE EVIDENCE.
   The Chartmetric extraction cannot be re-run (archive floor 2024-01-01, tier
   denials), so these files are the only record of it and must never be edited.

**Precedence, as implemented in `backend/scripts/merge_final_delivery.py`:**
where both providers answer the same (artist, platform, variable, geo, date),
the Chartmetric value is kept because it is the already-delivered figure.
