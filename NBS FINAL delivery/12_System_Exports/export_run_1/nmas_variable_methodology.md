# NMAS Variable Methodology

### Variable: Bandsintown_followers_daily
- Source: Chartmetric Developer API
- Endpoint: /api/artist/{chartmetric_id}/stat/bandsintown
- Field: value, followers, bandsintown_followers, trackers
- Definition: Daily Bandsintown follower/tracker count for an artist.
- Unit: followers
- Generation: Raw provider extraction. Quarterly rule: net_change.
- Coverage limitations: Bandsintown metrics may have limited coverage for some artists.
- Geo limitations: Global aggregate only.
- Platform scope: Bandsintown
- Fallback logic: No fallback.
- Missing data treatment: Preserve gaps as-is. No interpolation.
- Status: observed
